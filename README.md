# SessionX

A lightweight Windows application for managing Roblox accounts and Roblox client sessions.

> [!IMPORTANT]
> SessionX is uncompleted project. So please do not come and complaining to our team.

## Features

* Account management
* Roblox profile information
* Account search and filtering
* Favorites
* Roblox client detection
* Running client counter
* Client process information
* Focus or terminate a running Roblox client
* Optional application authentication
* Password protection
* Passkey and Windows Hello support
* Dark and light themes
* Local account data

## Status

SessionX is currently in development.

Features may change as the project develops.

## Requirements

* Windows 10 or later
* [.NET 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

## Building

Clone the repository:

```bash
git clone https://github.com/DuckyCashy/RobloxAccountManager.git
```

Open `SessionX.sln` in Visual Studio and build the solution.

## Security

Roblox Account Manager is designed to manage account information locally.

The application does not require Roblox passwords or `.ROBLOSECURITY` cookies to manage accounts.

Authentication features are optional and disabled by default.
